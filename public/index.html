Welcome to the Capstone Lab program

If you are reading this, a container built from this repository is running on Cloud Run and answering requests. That is the whole path working: source, image, registry, deploy, URL.

To make it yours:

  1. Clone this repository, or use it as a template.
  2. Edit public/index.html and say something else.
  3. Push to main.
  4. Watch the deploy, then reload your own URL.

The Dockerfile is the part worth reading. It listens on $PORT and binds 0.0.0.0, which is the difference between a container that runs on your laptop and one that runs here.
